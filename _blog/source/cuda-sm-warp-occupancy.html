CUDA：SM 资源限制、Warp 调度与 Occupancy

从 Kernel 资源需求出发，观察它如何限制 resident blocks / warps，并进一步影响 occupancy 与 SM 内部调度。

⑤ 核心逻辑

一个 SM 不是先决定“我要 64 个 warp”，而是不断装入 Block。每装入一个 Block，就同时消耗 threads、registers、shared memory、block slot 和 warp slot。 任意一种资源先达到上限，就不能继续装新的 Block。最终： resident blocks × warps/block = resident warps，而 occupancy = resident warps / SM 最大 warps。 Resident warp 只是“已经驻留并占资源”，真正每周期执行哪些 warp，还要由 Warp Scheduler 从 ready warps 中选择并 issue。
