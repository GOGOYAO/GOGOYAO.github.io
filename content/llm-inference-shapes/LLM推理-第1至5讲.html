教学模型
[B,S,D] 表示：B 条序列，每条 S 个 token，每个 token 一个 D 维向量。D = H × d；本例 F = 4D。
调整后，第 2–4 讲的 shape 同步更新。数值演示与第 5 讲使用独立固定例子。模型为 GPT-2 风格 pre-norm；推理模式，省略 dropout。
01

推理全景

先区分三个对象：一次模型前向、一次选 token、一个生成循环。

第 1 讲自测 · 3 个问题
  1. logits 是 token ID、概率，还是分数？
  2. 生成 3 个新 token，普通生成需要几次模型前向？
  3. 换一个 prompt，哪些东西通常不变？
查看答案
① 分数；softmax 后才是概率。② 3 次：prompt 前向选出第 1 个，再两次选出第 2、3 个。③ 模型参数与 D、H、F、V、L 通常不变；输入长度和激活可能变化。

03

完整模型结构

先看整条路径，再拆开 Embedding、残差、归一化和 FFN；Attention 在下一讲展开。

第 3 讲自测 · 读懂骨架
  1. 增加输入长度 S，D 会变大吗？
  2. FFN 是否让一个 token 直接读取另一个 token？
  3. 残差连接使特征维从 D 变成 2D 吗？
  4. 生成时 [B,1,V] 中的 1，是否说明模型只处理了一个输入 token？
查看答案
① 不会，D 是模型配置。② 不会；本例的跨位置交互由 Attention 完成。③ 不会，残差是相加。④ 不说明；输入可以是完整 S 个 token，只在输出端取最后位置。
04

Attention 的 shape 全过程

两次矩阵乘法：先决定“看谁”，再对那些位置的值做加权求和。

第 4 讲自测 · 从输入推到输出
  1. B=2、S=5、D=8、H=2 时，拆头后的 Q shape 是什么？
  2. Q @ Kᵀ 的输出为什么有两个 S？
  3. softmax 沿哪个轴？每个 Query 可以访问未来 token 吗？
  4. 把所有 head 合并后，为什么又回到 D？
查看答案
① [2,2,5,4]。② 行表示 Query 位置，列表示 Key 位置。③ 沿最后的 Key 轴；因果 mask 屏蔽未来。④ H×d=D，合并是还原特征维，不是把 token 拼到一起。
05

不使用 KV Cache 的生成

每步把完整上下文重新输入：输出只有一个 token，中间却重新计算许多旧位置。

第 5 讲自测 · 找出重复计算
  1. P=4、G=3，三次前向的输入长度分别是多少？
  2. 最后一次刚选出的 token，是否已经作为输入算过？
  3. 无缓存时，为什么 [B,1,V] 的 logits 不能证明中间计算只有一个位置？
  4. 新 Query 是否仍然需要历史位置的信息？
查看答案
① 4、5、6。② 没有；只有继续生成时它才进入下一次前向。③ 这是输出端只取最后位置；模型主体仍算完整上下文。④ 需要历史 K/V；可以减少旧位置的重复生成，却不能丢掉上下文信息。
06

KV Cache、prefill / decode 与 GQA

保存历史 K/V，让新 token 的前向接着算；用同一段生成过程追踪全部 shape。

承接第 5 讲：固定 prompt 为 p₀ p₁ p₂，生成 g₁ g₂ g₃。本节使用独立小模型：B=1，D=8，Hq=4，d=2，L=2，词表大小=8；不改变前面各讲的配置。
为何缓存→GQA→生成时间线→shape→数值计算→每层缓存
第 6 讲自测 · 把生成过程串起来
  1. prompt 长度为 3，生成 3 枚 token：有缓存时三次前向的输入长度分别是多少？
  2. 第 1 次 decode 的 T、S、注意力分数 shape 是什么（默认 Hq=4）？
  3. 默认 GQA 下，Q 与缓存 K/V 的头数各是多少？
  4. 哪些 Query head 共用 KV head 0？它们的概率和输出必须相同吗？
  5. 为什么缓存 K/V，而不缓存历史 Q？
  6. 生成结束时 g₃ 已经写入缓存了吗？
  7. 切到 MHA 时，Q 头数变化吗？相同长度的 KV 缓存变多还是变少？
  8. 后续 token 加入后，为什么历史各层的 K/V 可以复用？
查看答案
① 3、1、1。② T=3、S=1，分数 [1,4,1,4]。③ Q 有 4 头，K/V 各 2 头。④ Q0、Q1；Query 不同，概率与输出不必相同。⑤ 新 Query 要匹配历史 K 并汇总历史 V，不用历史 Q。⑥ 没有，它刚被选出，还没进入前向。⑦ Q 仍有 4 头；Hkv 从 2 到 4，缓存翻倍。⑧ 在本节假设下，因果 mask 阻止旧位置读取未来，参数、前缀和位置保持不变。
